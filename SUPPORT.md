# Support

PYDocs is maintained by one person. Support is best-effort, with no SLA.

- **Questions and bugs:** open a [GitHub issue](https://github.com/zachshallbetter/pydocs/issues/new/choose). For a bug, include the PYDocs version, your Python version and the input that triggers it.
- **Security reports:** follow [SECURITY.md](SECURITY.md). Do not open a public issue.
- **Versioning:** the package version is in `pyproject.toml` and changes are listed in [CHANGELOG.md](CHANGELOG.md). The project is pre-alpha; the `AssociationNode` schema is the contract to keep stable.
